Interpretation limits:
- Desktop Fedora environment with powersave governor and adaptive CPU boost; no fixed clocks or CPU isolation.
- Warm-cache synthetic workloads; not official ClickBench/TPC scores.
- Large DuckDB outputs include Python row conversion; Polars shares column buffers.
- No Linux process-footprint measurements; macOS libproc harness unavailable.
- Existing historical ARM64 reports use a different machine and are not paired regressions.
- Floating values use dyadic arithmetic for exact cross-engine fingerprints; this is not NaN/Inf performance coverage.
- Full sort and generic joins/distinct remain serial; worker counts are caps rather than a promise that every operator parallelizes.
- Individual sample ranges and per-round medians are preserved in summary.json; this is a first desktop baseline, not a controlled bare-metal ranking.
